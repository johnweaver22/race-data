# Excel export

Completed captures can export a genuine `.xlsx` workbook directly from results.
The export uses the same timing engine as the displayed results and captures
the completed race with a same-origin fetch using the current signed-in session.

## Contents

- Summary: swimmer, meet, event, course, export time in UTC, finish time,
  start-to-15m, final 5m and average 100m pace where applicable.
- Splits: event-specific half splits, four 100m stroke splits for 400m IM,
  or 100m splits for 800m/1500m. A 50m event explicitly has no half splits.
- Length Metrics: each length's distance, stroke, split, cumulative time,
  start/turn-to-15m, stroke rate, estimated m/s and estimated DPS.

Values are results only, with no spreadsheet formulas. Numbers remain numeric
at full precision, with two-decimal display formatting. Unavailable values stay
as dashes, including first-length turn-to-15m. First-length speed and DPS are
included. Table ranges and populated rows match the actual race distance.

## Download behaviour

Excel is generated locally from the workbook template when results appear.
The button executes the same synchronous Blob, object URL, download anchor,
click, remove and five-second URL cleanup sequence as Swim Clock exportCsv.
Only the MIME type, filename extension and generated bytes differ.

No race data is posted to a server for this download. No login navigation,
second control, native file picker or share-sheet branch is used.

## Validation

38 automated checks pass. These cover the generated workbook, all supported
race configurations and the synchronous download sequence, including byte
preservation. Device saving still needs a real browser check; generating correct
bytes is not proof that a device accepted its download.
